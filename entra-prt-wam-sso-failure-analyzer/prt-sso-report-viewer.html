PRT SSO Report Viewer

Reads the JSON from Detect-PrtSsoHealth.ps1

Runs offline

Why does this user keep getting sign-in prompts?

This page renders the report written by Detect-PrtSsoHealth.ps1: each signed-in user's Primary Refresh Token, the dsregcmd PRT diagnostics, WAM state, UPN and SID checks, and the AAD Analytic 1006–1007 authentication transactions they correlate with. It is one HTML file with no libraries and no network calls; the file is read by your browser and never leaves the machine.

  1. On the device, the report is at C:\ProgramData\EndpointWeekly\PrtSso\PrtSso-latest.json (written every time the Intune detection runs).
  2. Copy it off the device and choose Open a report file.

Sharing it outside your team? Run the script with -Anonymise first.

Part of entra-prt-wam-sso-failure-analyzer.
