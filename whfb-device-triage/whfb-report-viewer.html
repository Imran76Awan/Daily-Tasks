WHfB Device Report Viewer

Reads the JSON from Get-WHFBDeviceReport.ps1

Runs offline

Read one device's Windows Hello state

This page renders the JSON report written by Get-WHFBDeviceReport.ps1. It is a single HTML file with no libraries, no tracking and no network calls. The file you open is parsed by your own browser and never leaves the machine, so it is safe to use on a report that contains user names.

  1. Run Get-WHFBDeviceReport.ps1 in an elevated PowerShell on the device you are troubleshooting.
  2. It writes WHFB-Device-<name>-<date>.json beside itself.
  3. Select Open a report file above and choose that file.

Sharing a report outside your team? Re-run the script with -Anonymise, which masks user names, the device ID, the Hello key ID and certificate thumbprints.

Part of the whfb-device-triage scripts. Guide: EndpointWeekly.
